CS2 FOR APPLE SILICON MACS

You need: an M1 or newer Mac, macOS 14.6+, Rosetta 2, your own Steam account,
and about 100 GB free. An external SSD can hold the game.

Before starting, set your main display's desired refresh rate in macOS
System Settings > Displays. Setup saves that rate as the FPS cap.

FIRST-TIME SETUP

1. Open Install CS2.command. Choose a game folder and graphics profile.
   If unsure, choose Balanced — 1080p.

2. Click Copy Launch Options when the Mac setup finishes, then finish
   installing Windows Steam and sign in.

3. In Windows Steam > Settings > Storage, add V:\ as a game library.
   V: is the game folder you selected. Install Counter-Strike 2 there.

4. In Windows Steam's Library, right-click Counter-Strike 2 > Properties >
   General. Paste the copied text into Launch Options.
   Lost the copied text? See docs/setup.md or run bin/cs2-mac options.

5. Open CS2.app in your home folder's Applications folder.
   Start the game once, quit normally, then reopen CS2.app to finish
   applying the graphics preset.

PLAY NEXT TIME

Open CS2.app. Drag it into the Dock for easy access.
If Windows Steam shows its Library, press Play on Counter-Strike 2.
Keep your external SSD connected if that's where the game is installed.

Can't find CS2.app? In Finder > Go > Go to Folder, enter ~/Applications.

NEED HELP?

If macOS blocks a download, review its source and use the normal Open Anyway
flow in System Settings > Privacy & Security if you choose to allow it.
If Rosetta is missing, follow Apple's installation instructions first.
The toolkit never disables Gatekeeper or accepts Apple's terms for you.

Online matchmaking is reported working on the maintainer's M5 Max setup.
Fresh installs on other Macs still need testing. Performance varies;
occasional hitches remain in the measurements. FACEIT is unsupported.
